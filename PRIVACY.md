# Privacy

Adaptive Prompt Architect is an instructions-only Agent Skill. The repository does not operate a server, collect telemetry, request credentials, or independently transmit user content.

When the skill runs, the host product and any tools the user has enabled may process task content under their own privacy terms and controls. The skill instructs the host to use only relevant context and does not add authorization to access or disclose unrelated data.

Information submitted voluntarily through GitHub issues or pull requests is processed by GitHub and is publicly visible unless GitHub indicates otherwise. Do not include secrets or private conversation content in public reports.
