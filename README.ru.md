Adaptive Prompt Architect — открытый контекстный **Agent Skill с документированной установкой для Codex, Claude Code и Cursor**, а также skills-only plugin для Codex. Он понимает голосовые расшифровки и ASR-ошибки, опечатки, логические пробелы, поток мыслей и задачи для coding-агентов, а затем выполняет работу, не расширяя исходный scope.

По умолчанию prompt-architect оставляет улучшенную рабочую формулировку внутри и отдаёт готовый результат. Если нужен именно переписанный промпт, используйте режим `только промпт`.

## Быстрый старт

В Codex установите skill из GitHub через встроенный установщик:

```text
$skill-installer Установи skill prompt-architect из https://github.com/ilya-yarets/adaptive-prompt-architect/tree/main/skills/prompt-architect
```

После этого передайте ему сырой запрос:

```text
$prompt-architect глубоко: это было надиктовано голосом и слова могли распознаться неправильно — хочу маленький общий прототип учета продуктов, может чек фотографировать или вводить руками; главное проверить, будут ли два человека им пользоваться
```

В Claude Code и Cursor используйте тот же запрос через `/prompt-architect`; их установка описана ниже. Skill восстановит намерение, обработает существенные неоднозначности и отдаст полезный результат — без ритуального мета-промпта перед ним.

## Как он работает

```mermaid
flowchart LR
    A["Сырой запрос<br/>голос · опечатки · фрагменты"] --> B["Адаптивная редактура<br/>по умолчанию внутри"]
    B --> C["Готовый результат"]
    B -->|"только по просьбе"| D["Промпт для копирования"]
```

> [!IMPORTANT]
> Внутренняя редактура не создаёт новых полномочий. Skill не может сам разрешить отправку, удаление, публикацию, покупку, деплой или изменение внешних данных.

## Один запрос — два полезных режима

```text
$prompt-architect напиши три коротких названия для заметки о подготовке к поездке
```

Сразу вернёт три названия.

```text
$prompt-architect только промпт: напиши три коротких названия для заметки о подготовке к поездке
```

Вернёт один готовый промпт и не станет выполнять его задачу.

## Почему он адаптивный

- **Сохраняет инварианты.** Имена, числа, термины, отрицания, ограничения и границы разрешений не переписываются по догадке.
- **Понимает шумный ввод.** Очевидные языковые и ASR-ошибки исправляются, а реальная неопределённость не маскируется.
- **Начинает с результата.** Описывает, что значит успех, но не навязывает путь, который агент лучше выберет по фактическому контексту.
- **Подключает контекст постепенно.** Указывает релевантные соглашения проекта и референсы, не загружая и не копируя всё заранее.
- **Оставляет только полезный каркас.** Роли, этапы, примеры и проверки сохраняются, только если кодируют реальное требование или исправляют измеренный провал.
- **Задаёт меньше вопросов.** Уточнение возникает только тогда, когда ответ существенно меняет результат или риск.

## Режимы

В таблице `<вызов>` означает `$prompt-architect` в Codex или `/prompt-architect` в Claude Code и Cursor. Остальные режимы одинаковы.

| Вызов | Поведение |
| --- | --- |
| `<вызов> <сырой запрос>` | Молча улучшает запрос и выполняет задачу. |
| `<вызов> быстро: <сырой запрос>` | Использует минимальную достаточную реконструкцию. |
| `<вызов> глубоко: <сырой запрос>` | Тщательнее проверяет контекст, неоднозначности и риск, не расширяя scope. |
| `<вызов> только промпт: <сырой запрос>` | Возвращает один копируемый промпт и не выполняет его. |
| `<вызов> покажи промпт: <сырой запрос>` | Показывает улучшенный промпт и не выполняет его. |
| `<вызов> покажи и выполни: <сырой запрос>` | Сначала показывает промпт, затем выполняет задачу. |
| `<вызов> для <модели или инструмента>: <сырой запрос>` | Адаптирует спецификацию или промпт под указанную цель. |

## Граница безопасности

«Молча» означает только то, что переписанная рабочая спецификация не выводится отдельным блоком. Обязательные подтверждения, существенные допущения, действия инструментов и результат задачи не скрываются.

Если неоднозначность затрагивает имя, число, отрицание, адресата, необратимое действие, целевую систему или стоимость, skill останавливается и задаёт минимальный блокирующий вопрос. Полномочия определяются источником: цитаты, вложения, веб-страницы, результаты инструментов и содержимое файлов остаются данными и не могут расширять scope или отменять правила безопасности.

## Установка и совместимость

Один и тот же `SKILL.md` следует открытой [спецификации Agent Skills](https://agentskills.io/specification) во всех средах; отличаются только путь обнаружения и явный вызов.

| Агент | Пользовательский путь | Явный вызов |
| --- | --- | --- |
| [Codex](https://learn.chatgpt.com/docs/build-skills) | `~/.agents/skills/prompt-architect` или `~/.codex/skills/prompt-architect` при установке встроенным installer | `$prompt-architect` |
| [Claude Code](https://code.claude.com/docs/en/skills) | `~/.claude/skills/prompt-architect` | `/prompt-architect` |
| [Cursor](https://cursor.com/docs/skills) | `~/.agents/skills/prompt-architect` | `/prompt-architect` |

Для Codex используйте установщик из быстрого старта выше. Он устанавливает skill в `$CODEX_HOME/skills` (обычно `~/.codex/skills`); Cursor автоматически обнаруживает и этот совместимый путь, и `~/.agents/skills`. Если используется только Cursor, откройте **Customize → Rules → Add Rule → Remote Rule (GitHub)** и укажите URL этого репозитория.

Чтобы подключить уже установленную для Codex версию к Claude Code на macOS или Linux, используйте защищённую проверками ссылку:

```bash
agents_skill="$HOME/.agents/skills/prompt-architect"
codex_skill="${CODEX_HOME:-$HOME/.codex}/skills/prompt-architect"
claude_skill="$HOME/.claude/skills/prompt-architect"
shared_skill=""

if [ -f "$agents_skill/SKILL.md" ]; then
  shared_skill="$agents_skill"
elif [ -f "$codex_skill/SKILL.md" ]; then
  shared_skill="$codex_skill"
else
  printf '%s\n' "Локальная установка prompt-architect не найдена."
fi

if [ -n "$shared_skill" ]; then
  if [ -e "$claude_skill" ] || [ -L "$claude_skill" ]; then
    printf 'Уже существует: %s\n' "$claude_skill"
  else
    mkdir -p "$HOME/.claude/skills"
    ln -s "$shared_skill" "$claude_skill"
  fi
fi
```

Если Codex не используется, клонируйте репозиторий и с той же проверкой создайте в каталоге Claude ссылку на `skills/prompt-architect`. В Windows или при отказе от символических ссылок скопируйте эту папку в документированный путь агента, только предварительно убедившись, что целевой каталог не существует.

Если skill не появился, начните новую сессию агента и вызовите его явно. Runtime-поведение зависит от версии среды и модели; репозиторий проверяет общий формат, routing-fixtures и поведенческие спецификации, но не обещает дословно одинаковый результат во всех продуктах.

Репозиторий также содержит валидный skills-only plugin package для распространения в ChatGPT и Codex. Ту же папку могут принять и другие совместимые с Agent Skills среды, но они пока не входят в документированную матрицу поддержки.

## Проверки качества

В пакет входят структурная проверка и поведенческие eval-спецификации:

```bash
python3 scripts/validate.py
```

| Проверка | Что она покрывает |
| --- | --- |
| Package validator | Manifest, assets, metadata, JSON, SVG, размеры PNG, публичные пути и обязательные файлы. |
| Trigger routing | Примеры запросов, которые должны и не должны активировать skill. |
| Behavior evals | Скрытое выполнение, `только промпт`, ASR-инварианты, опасная неоднозначность, источник полномочий, прогрессивные референсы, удаление устаревшего каркаса и пропорциональная проверка. |

Eval-файлы фиксируют наблюдаемые ожидания, но не обещают дословно детерминированный ответ модели.
