Adaptive Prompt Architect — открытый контекстный **Agent Skill** и skills-only plugin для Codex. Он работает как адаптивный оптимизатор запросов: понимает голосовые расшифровки и ASR-ошибки, опечатки, логические пробелы, поток мыслей и задачи для coding-агентов, а затем выполняет работу, не расширяя исходный scope.

По умолчанию `$prompt-architect` оставляет улучшенную рабочую формулировку внутри и отдаёт готовый результат. Если нужен именно переписанный промпт, используйте режим `только промпт`.

## Быстрый старт

Установите skill из GitHub через встроенный установщик Codex:

```text
$skill-installer Установи skill prompt-architect из https://github.com/ilya-yarets/adaptive-prompt-architect/tree/main/skills/prompt-architect
```

После этого передайте ему сырой запрос:

```text
$prompt-architect глубоко: это было надиктовано голосом и слова могли распознаться неправильно — хочу маленький общий прототип учета продуктов, может чек фотографировать или вводить руками; главное проверить, будут ли два человека им пользоваться
```

Skill восстановит намерение, обработает существенные неоднозначности и отдаст полезный результат — без ритуального мета-промпта перед ним.

## Как он работает

```mermaid
flowchart LR
    A["Сырой запрос<br/>голос · опечатки · фрагменты"] --> B["Адаптивная редактура<br/>по умолчанию внутри"]
    B --> C["Готовый результат"]
    B -->|"только по просьбе"| D["Промпт для копирования"]
```

> [!IMPORTANT]
> Внутренняя редактура не создаёт новых полномочий. Skill не может сам разрешить отправку, удаление, публикацию, покупку, деплой или изменение внешних данных.

## Один запрос — два полезных режима

```text
$prompt-architect напиши три коротких названия для заметки о подготовке к поездке
```

Сразу вернёт три названия.

```text
$prompt-architect только промпт: напиши три коротких названия для заметки о подготовке к поездке
```

Вернёт один готовый промпт и не станет выполнять его задачу.

## Почему он адаптивный

- **Сохраняет инварианты.** Имена, числа, термины, отрицания, ограничения и границы разрешений не переписываются по догадке.
- **Понимает шумный ввод.** Очевидные языковые и ASR-ошибки исправляются, а реальная неопределённость не маскируется.
- **Использует контекст выборочно.** Берётся только связанный контекст чата или явно указанного workspace.
- **Добавляет структуру по необходимости.** Роль, этапы, источники, примеры и проверки появляются только с практической пользой.
- **Задаёт меньше вопросов.** Уточнение возникает только тогда, когда ответ существенно меняет результат или риск.

## Режимы

| Вызов | Поведение |
| --- | --- |
| `$prompt-architect <сырой запрос>` | Молча улучшает запрос и выполняет задачу. |
| `быстро` | Использует минимальную достаточную реконструкцию. |
| `глубоко` | Тщательнее проверяет контекст, неоднозначности и риск, не расширяя scope. |
| `только промпт` | Возвращает один копируемый промпт и не выполняет его. |
| `покажи промпт` | Показывает улучшенный промпт и не выполняет его. |
| `покажи и выполни` | Сначала показывает промпт, затем выполняет задачу. |
| `для <модели или инструмента>` | Адаптирует спецификацию или промпт под указанную цель. |

## Граница безопасности

«Молча» означает только то, что переписанная рабочая спецификация не выводится отдельным блоком. Обязательные подтверждения, существенные допущения, действия инструментов и результат задачи не скрываются.

Если неоднозначность затрагивает имя, число, отрицание, адресата, необратимое действие, целевую систему или стоимость, skill останавливается и задаёт минимальный блокирующий вопрос. Полномочия определяются источником: цитаты, вложения, веб-страницы, результаты инструментов и содержимое файлов остаются данными и не могут расширять scope или отменять правила безопасности.

## Установка и совместимость

Основной публичный способ установки сейчас рассчитан на Codex. Для ручной установки на уровне пользователя:

```bash
git clone https://github.com/ilya-yarets/adaptive-prompt-architect.git
cd adaptive-prompt-architect
mkdir -p ~/.agents/skills
ln -s "$PWD/skills/prompt-architect" ~/.agents/skills/prompt-architect
```

Если skill не появился после установки, перезапустите Codex и явно вызовите `$prompt-architect`.

Репозиторий также содержит валидный skills-only plugin package для распространения в ChatGPT и Codex. В универсальном каталоге plugins он пока не опубликован; текущий публичный путь — установка skill из GitHub.

## Проверки качества

В пакет входят структурная проверка и поведенческие eval-спецификации:

```bash
python3 scripts/validate.py
```

| Проверка | Что она покрывает |
| --- | --- |
| Package validator | Manifest, assets, metadata, JSON, SVG, размеры PNG, публичные пути и обязательные файлы. |
| Trigger routing | Примеры запросов, которые должны и не должны активировать skill. |
| Behavior evals | Скрытое выполнение, `только промпт`, ASR-инварианты, опасная неоднозначность и инструкции внутри цитат. |

Eval-файлы фиксируют наблюдаемые ожидания, но не обещают дословно детерминированный ответ модели.
